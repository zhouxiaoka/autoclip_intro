    开发者

    一条命令出片，也能交给 Agent。

    桌面应用、命令行和 MCP 共用同一套流程和数据目录。命令行出的项目，在桌面端首页直接可见。

    • CLI批量处理，--json 输出给脚本和流水线。
    • MCP7 个工具，Claude、Cursor、opencode 等 Agent 可以直接调用出片。
    • Docker自建 Web 服务，跑在服务器或 NAS 上。
    # 本地模型，一条命令出片 $ autoclip produce talk.mp4 --platform youtube_shorts --json # 导出 Shorts 竖屏版 $ autoclip outputs PROJECT_ID --export-kits # 接入 opencode 等 MCP 客户端 $ autoclip mcp install opencode

    常见问题

    你大概想问的。

    可复现的 Bug 用 GitHub Issues。讨论：公告、第一次出片、想法与路线图。已知问题见 置顶帖。

    第一次出片卡住？去 第一次出片问答。

    要花钱吗？

    AutoClip 免费、MIT 开源。云端分析、转写与生图按所选服务商计费。2026-10-01 在 Apple Silicon Mac 上使用 qwen-plus 文字模型和作者字幕，1 小时 43 分钟的 Jensen 访谈生成 10 条成片，文字模型费用估算约 ¥0.09；不含云端转写、生图和投稿服务费用。Ollama / LM Studio 本地分析没有云端模型费用，需相应硬件。

    我的视频会被上传吗？

    剪辑、取景与渲染在你的电脑上完成。云端分析会发送相关字幕与文案；可选的画面理解或参考帧生图会发送所需抽样画面，云端转写会发送音频。使用本地分析与本地转写时不需要对应云端 API。成片只有选择投稿后才上传到已连接的平台。

    支持哪些视频来源？

    YouTube、B 站链接和本地文件。有作者字幕时可直接使用；没有字幕可使用本地 Whisper / SenseVoice 或配置的云端转写。

    为什么第一次打开系统会警告？

    安装包还没有做 Apple 公证和 Windows 代码签名。macOS 右键应用选「打开」；Windows 点「更多信息」再选「仍要运行」。之后不会再提示。

    片段选得不好怎么办？

    先换一个更强的模型试试。仍不理想，请在 GitHub 置顶帖告诉我们视频类型、时长和模型，我们在收集样例改进挑片。

    第一次怎么试？

    先用一条 10–30 分钟、有字幕的访谈或播客，选一两个平台。卡住时看 第一次出片问答。

    怎么发布到 B 站和海外平台？

    在设置里配 Upload-Post 密钥和 B 站 Cookie，成片页勾选平台，默认先发到「仅自己」。逐步说明见 发布教程。
