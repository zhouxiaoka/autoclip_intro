怎么工作

三步，从一条长视频到一组切片。

01

导入

粘一条 B站或 YouTube 链接，或者直接拖入本地视频。没有字幕的视频，可以一键在本地安装 Whisper 转写，不必先去别处生成字幕。

链接文件
https://www.bilibili.com/video/BV1…
开始
bilibiliYouTube本地 mp4 / mov / mkv可选 SRT 字幕
02

理解

大模型读完整条视频的内容，按话题切分、逐段评分，挑出真正值得单独看的片段，并为每段写好标题。用哪个模型你自己定：通义千问、OpenAI、Gemini、硅基流动，或任何 OpenAI 兼容接口。

12:04–14:31为什么我放弃了订阅制9.2
27:50–31:12第一个付费用户是怎么来的8.8
48:19–50:02一个人做产品最怕的事8.5
55:40–57:10闲聊：最近在看的书6.1
03

出片

切片和合集直接生成到本地。标题可以顺手改，合集里拖拽排序。切片可一键发布到海外平台与 B 站（设置里贴一次 Cookie：SESSDATA、bili_jct、DedeUserID，一个账号；海外走你自己的 Upload-Post）。剩下的时间，留给下一条视频。

为什么是 AutoClip

一个认真做内容的人，会想要的工具。

01

全程本地

视频不上传到任何服务器。下载、转写、切片、合成都在你的电脑上完成，只有字幕文本会发给你选择的模型。

02

零依赖安装

安装包自带便携 Python 与静态 ffmpeg。不用配环境、不用装 Docker，下载即用。

03

模型自选

不绑定任何厂商。API Key 填在自己的设置页里，随时切换提供商或接入自定义 OpenAI 兼容地址，包括本地模型。

04

开源 MIT

全部代码在 GitHub。想看它怎么处理你的视频、想改、想自己部署，都可以。

要花钱吗？

AutoClip 本身免费、开源（MIT）。唯一的成本是你自己模型的 API 调用费——每条视频通常只是几分钱到几毛钱，取决于时长和所选模型。

我的视频会被上传吗？

不会。视频文件只在你的电脑上处理。发给模型的只有字幕文本（用于理解内容和评分），发给哪家由你在设置里决定。

支持哪些视频来源？

B站链接、YouTube 链接、本地文件。有字幕的视频直接用；没有字幕的可以在设置里一键安装 Whisper，在本地转写。

为什么第一次打开系统会警告？

因为安装包还没有做 Apple 公证 / Windows 代码签名。macOS 右键 → 打开；Windows 点「更多信息」→「仍要运行」。之后不会再提示。签名正在计划中。

切片效果不好怎么办？

先试换一个更强的模型。仍不理想的话，请通过 反馈表单或 GitHub 置顶帖告诉我们视频类型、时长、模型，我们在收集样例改进评分策略。

第一次怎么试？

自备短样片。多为英语对白，可开官方字幕或走 Whisper / 自备 SRT。示例 · 非托管 · 自担使用权：Sources Podcast · Sam Altman on Astra/AGI（Sources Podcast，不是 OpenAI 频道）。卡住时看 第一次出片问答。

怎么发布到 B 站和海外平台？

在设置里配 Upload-Post 密钥和 B 站 Cookie，切片页勾选平台，默认先发到「仅自己」。逐步说明见 发布教程。
