开发者

一条命令出片，也能交给 Agent。

  • CLI
  • MCP
  • Docker
# 本地模型，一条命令出片 $ autoclip run talk.mp4 --provider ollama --json # 导出 Shorts 竖屏版 $ autoclip export PROJECT_ID --preset shorts # 接入 opencode 等 MCP 客户端 $ autoclip mcp install opencode
