为什么是 AutoClip

一个认真做内容的人，会想要的工具。

01

本机剪辑与渲染

剪辑与渲染在本机完成。云端文字分析发送相关字幕/文案；云端视觉分析发送抽样画面及必要文字。由你选择服务商，发布时才上传成片到目标平台。

02

零依赖安装

安装包自带便携 Python 与静态 ffmpeg。不用配环境、不用装 Docker，下载即用。

03

模型自选

不绑定厂商，自备 API Key（BYOK）。云端可选 Qwen、OpenAI、Gemini、DeepSeek、Doubao Seed、Kimi、GLM、Grok，费用由所选服务商计费。本地可用 Ollama / LM Studio。

04

开源 MIT

全部代码在 GitHub。想看它怎么处理你的视频、想改、想自己部署，都可以。

文字、视觉与转写费用取决于你的配置和服务商。智能选择先用本地证据；付费视觉初筛需单独启用。

我的视频会被上传吗？

剪辑与渲染在本机完成。云端文字分析发送相关字幕/文案；云端视觉分析发送抽样画面及必要文字。由你选择服务商，发布时才上传成片到目标平台。

支持哪些视频来源？

B站链接、YouTube 链接、本地文件。有字幕的视频直接用；没有字幕的可以在设置里一键安装 Whisper，在本地转写。

为什么第一次打开系统会警告？

因为安装包还没有做 Apple 公证 / Windows 代码签名。macOS 右键 → 打开；Windows 点「更多信息」→「仍要运行」。之后不会再提示。签名正在计划中。

切片效果不好怎么办？

先试换一个更强的模型。仍不理想的话，请通过 反馈表单或 GitHub 置顶帖告诉我们视频类型、时长、模型，我们在收集样例改进评分策略。

第一次怎么试？

自备短样片。多为英语对白，可开官方字幕或走 Whisper / 自备 SRT。先试 Jackie Dowling | Stanford Energy Fellow（Stanford ENERGY · 约 3:47）。示例 · 非托管 · 自担使用权。其他示例不必都试：The State of Startups in 2026（Y Combinator）；Sources Podcast · Sam Altman on Astra/AGI（Sources Podcast，不是 OpenAI 频道）。卡住时看 第一次出片问答。

怎么发布到 B 站和海外平台？

在设置里配 Upload-Post 密钥和 B 站 Cookie，切片页勾选平台，默认先发到「仅自己」。逐步说明见 发布教程。

从游戏录屏，到值得分享的高光。

用视觉理解寻找画面中的精彩事件，生成可编辑的高光与推广草稿。在同一个工作区调整边界、画幅和文字，再导出成片。

字幕分析 · 低成本

适合访谈、课程和有解说的视频。使用字幕与文字模型；旧配置默认保留此路线，无对白的游戏动作不靠字幕判断。

视觉分析 · 画面事件

适合需要理解动作的录屏。自行配置多模态模型并选择视觉分析；仅配置模型不代表授权调用。

文字、视觉与转写费用取决于你的配置和服务商。智能选择先用本地证据；付费视觉初筛需单独启用。

新能力

v1.4.0：游戏视觉、双路线，确认后再剪。

默认是字幕分析。视觉分析可选；付费视觉初筛需要明确开启。导入之后先确认，再进入同一个编辑器。发布与自动封面自 v1.3.2 起可用，不是 v1.4.0 的新功能。

游戏视觉分析

从录屏里找画面事件。跑酷样片不能代表所有游戏。边界、裁切和文案需要人工复核，不承诺投放效果。

字幕默认，视觉可选

字幕路线发送文字。视觉路线可能把抽样画面和必要文字发给你选择的云端服务商。只配置模型不等于允许调用。
