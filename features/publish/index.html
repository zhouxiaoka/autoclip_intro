剪完就能发——海外平台与 B 站，同一页勾选

导入 → 理解 → 出片之后，在切片上点「发布」。剪辑仍在你电脑里；只有你点了发布，成片才离开本机。

下载 v1.3.2 想法与路线图

v1.3.2 已包含发布页。仍在用 v1.3.1 的，请更新到 v1.3.2。

同一页勾选

切片上打开「发布」，海外平台和 B 站放在一起选。海外走你自己的 Upload-Post，以实际连上的账号为准。B 站在设置里粘贴一次 Cookie（须含 SESSDATA、bili_jct、DedeUserID），一个账号。

点了才离开本机

下载、转写、切片、合成仍在你的电脑上。发给模型的仍是字幕文本。成片只有在你点了「发布」之后，才会发到已连接的平台。也可以只下载，不发布。

现在发，或排到以后

可以现在发，也可以定时。B 站的定时须晚于现在两小时。项目页能看发布记录和月历，还没发出的排期可以取消。「排这一周」只排海外：周一、周三、周五 09:00，不含 B 站。

适合

已经用 AutoClip 出片，接下来要发到 TikTok、YouTube 或 B 站。希望先以「仅自己」试发，再决定要不要公开。一个 B 站账号就够。

不适合

要从这里一键发到抖音、小红书、快手；把 Upload-Post 的免费档或每日额度当成 AutoClip 的配额承诺；还在找旧的多账号 / 扫码 / 健康分流程；或手头安装包仍是 v1.3.1。

能力表（有）

  • 切片上「发布」；海外：用户自备 Upload-Post（已连平台勾选）。
  • B 站：设置贴一次 Cookie（SESSDATA / bili_jct / DedeUserID），单账号。
  • 现在发 / 定时；标题描述可空则用切片标题；字幕烧录默认开；约 4s 标题卡默认开。
  • 「仅自己」只承诺 TikTok / YouTube / B 站。
  • 可只下载不发布；项目页记录 / 月历 / 取消排期；「排这一周」仅海外、不含 B 站。
  • 画幅：竖屏账号 → 9:16 且不截 60s；仅 B 站 → 横屏；仅 LinkedIn / X 等 → 原画；竖屏 + B 站同次 → 各自渲。
  • 剪辑本机；点发布后成片才出站。
  • 同版可带自动封面，降低 B 站空封面被拒；细节见该页。

勿写

  • 抖音 / 小红书 / 快手一键发。
  • Reddit。
  • CLI / MCP 发 B 站。
  • 旧多账号 / 扫码 / 健康分。
  • Upload-Post 额度写成 AutoClip 承诺。
  • v1.3.1 已可用。

成功标准

装上含发布页的版本后，15 分钟内完成「配好 Upload-Post 或 B 站 Cookie → 勾一个平台 → 仅自己可见试发成功（或明确失败原因）」；剪辑过程仍无成片上传。
