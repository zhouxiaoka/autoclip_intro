剪完就能发——海外平台与 B 站，同一页勾选

导入 → 理解 → 出片之后，在切片上点「发布」。剪辑仍在你电脑里；只有你点了发布，成片才离开本机。

查看最新版本 想法与路线图

发布需要含这一页的安装包。上面的链接不会把 v1.3.1 说成已经能发。

同一页勾选

切片上打开「发布」，海外平台和 B 站放在一起选。海外走你自己的 Upload-Post，以实际连上的账号为准。B 站在设置里粘贴一次 Cookie（须含 SESSDATA、bili_jct、DedeUserID），一个账号。

点了才离开本机

下载、转写、切片、合成仍在你的电脑上。发给模型的仍是字幕文本。成片只有在你点了「发布」之后，才会发到已连接的平台。也可以只下载，不发布。

现在发，或排到以后

可以现在发，也可以定时。B 站的定时须晚于现在两小时。项目页能看发布记录和月历，还没发出的排期可以取消。「排这一周」只排海外：周一、周三、周五 09:00，不含 B 站。

适合

已经用 AutoClip 出片，接下来要发到 TikTok、YouTube 或 B 站。希望先以「仅自己」试发，再决定要不要公开。一个 B 站账号就够。

不适合

要从这里发到抖音、小红书、快手；还在找以前的「多个 B 站账号一键上传」；或手头安装包仍是 v1.3.1。Upload-Post 的免费档和每日额度也不是 AutoClip 的承诺。

可见范围

平台支持时，可见范围默认「仅自己」。AutoClip 对外只对 TikTok、YouTube、B 站承诺仅自己 / private。其它平台即使能选可见范围，也不把「仅自己」写成保证。

有

  • 切片就绪后，在切片上打开「发布」。海外和 B 站在同一页。
  • 海外走你自己的 Upload-Post，以及你在那里连接的平台：TikTok、Instagram、YouTube、Facebook、LinkedIn、X、Threads、Pinterest、Bluesky、Discord、Telegram、Google Business。以该账号实际连接的为准。
  • B 站在设置里粘贴一次 Cookie，须含 SESSDATA、bili_jct、DedeUserID。一个账号。
  • 可以现在发，也可以定时。B 站定时须晚于现在两小时。标题和描述可以不填，默认用切片标题。
  • 字幕烧录默认打开。片头约 4 秒的标题卡默认打开。
  • 也可以只下载成片、不发布。
  • 项目页可以查看发布记录和月历，并取消尚未发出的排期。「排这一周」只排海外平台。
  • 画幅跟着要发的账号：有竖屏账号时渲成 9:16，不按 60 秒截断。只发 B 站时用横屏。只有 LinkedIn、X 这类横屏账号时用原画。竖屏和 B 站放在同一次时，各自单独渲染。
  • 同一版可以在发布时自动生成封面，用来避开 B 站空封面被拒。细节见 自动封面。

勿写

  • 抖音、小红书、快手没有投稿接口，不会出现在选择里。
  • Reddit 当前不可用，不从这里发出去。
  • 命令行目前只发海外平台。不要写成可以用 CLI 发 B 站。
  • 不再是旧的「多个 B 站账号一键上传」。B 站是一个账号。
  • Upload-Post 的免费档、付费档，以及各平台每日额度，以其自己的页面为准，不是 AutoClip 的配额承诺。AutoClip 本身仍免费，模型费用自理。
  • 已发布的 v1.3.1 安装包没有这一页。不要写成现在下载就能用。

什么时候能用

等安装包里带上这一发布页，再更新。当前 v1.3.1 的下载还没有。
