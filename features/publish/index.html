建议先「仅自己」试发再公开（TikTok / YouTube / B 站支持）。仍在用 v1.3.1 的，请更新到 v1.3.2。

适合谁

已经用 AutoClip 剪出高光，下一步想发到自己连上的平台，而不是再导出到另一个工具里重做一遍。

播客 → Shorts / TikTok

长对谈里的一句高光，剪成短片，发到 Shorts 或 TikTok。

课程 → B 站试发

一节课里的知识点，先发到 B 站自己看，确认没问题再公开。

访谈 → 海外和 B 站

同一段访谈，海外平台和 B 站可以用不同的画幅分别发出去。

怎么发

  1. 01

    设置里配一次就好。海外平台用你自己的 Upload-Post；B 站贴一次 Cookie，一个账号。

  2. 02

    在切片上点「发布」，勾选要发的平台。标题可以沿用切片标题。

  3. 03

    现在发，或排到以后。默认可以先「仅自己」；也可以只下载，不发布。
