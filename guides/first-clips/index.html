AutoClip 首次出片教程：有字幕与无字幕的视频怎么开始

先用一段自己拥有或获授权的 10–30 分钟素材，跑通输入、分析、成片和交付包，再处理整期播客。AutoClip 是开源桌面工具，视频剪辑与渲染在本地完成，模型可选云端或本地。

1. 安装正式版本，先检查机器

从官网或 GitHub Releases 下载适合机器的安装包。当前桌面包面向 macOS Apple Silicon 和 Windows x64；操作系统与安装问题以仓库的安装指南为准。首次启动可能需要下载转写模型，请给下载和磁盘空间留出余量。不要把安装完成当作已能成功出片。

2. 配好分析模型，测试连接

在设置中选择模型服务，填写你自己的 API Key 并测试连接；也可以配置 Ollama 或 LM Studio 的本地模型。软件免费不代表云端模型调用免费，实际账单由服务商决定。先关闭不需要的云端转写、参考帧分析或生图选项，减少首次排查的变量。

3. 根据字幕条件选择输入

YouTube、B 站链接或本地视频都可以作为输入。有作者字幕时优先使用现成字幕；本地文件可配套导入 SRT。没有字幕时，使用已安装的本地转写模型，或主动选择已配置的云端转写。云端转写会发送音频；字幕、时间轴和说话人错误都需要检查。

4. 先选一个平台，运行一键出片

先选抖音、小红书或 YouTube Shorts 中的一个目标平台，再运行一键出片。平台选择影响画幅、字幕、封面与发布文案；短于三分钟的素材适合先试 Shorts 或 B 站，当前 YouTube 长视频入口至少生成 180 秒完整片段。处理时间受视频长度、字幕、模型和硬件影响。

5. 检查完整片段，再保存交付包

播放每条成片，确认问题与回答完整、字幕没有遮住脸或关键信息、开头能独立理解、结尾没有截断。保存视频、封面和发布文案，核对标题是否忠实于原意。自动生成后仍需你判断是否适合发布；选择发布功能时才上传到对应平台。

卡住时，先区分是哪一步

下载失败先确认链接与网络；转写失败先确认模型下载完成，也可以用配套 SRT 做对照；模型调用失败先测试连接和余额；渲染失败记录平台、原片信息、版本与日志。反馈时不要公开 API Key。安装包点击、安装成功和首次成功出片是三个不同结果。
