TIM × 罗永浩：无字幕长访谈本地转写与切片

查看原片 · 原片版权属于原作者。此页展示已有公开案例的自动输出，不构成转发授权。

这条约 65 秒成片，讨论创作者面对快速走红时如何保持清醒。原片没有字幕，先用本地 Whisper base 转写，再分析并生成平台视频、封面和文案。

原片与这条输出

原片为「【正片】影视飓风TIM×罗永浩！用影像打开世界的梦想家」，来自罗永浩的十字路口，长度约 2 小时 52 分钟，中文，没有现成字幕。这条输出选择抖音平台与访谈版式，原片约 01:46:49 起，时长约 65 秒。

实测过程与条件

2026 年 10 月 1 日，Apple Silicon Mac、单队列低优先级运行。先本地 Whisper base 转写，再用 qwen-plus 分析；18 个候选、10 条渲染成片，约 29.5 分钟。文本模型费用估算约 ¥0.20，按历史 token 与当时估算单价计算；本地转写无云端转写 API 费，硬件、时间、生图与发布服务等费用未包含。

视频之外还交付什么

这条片段的封面标题为「红得快的网红 / 糊得更快」，发布文案围绕保持清醒、长期创作。自动标题需要结合完整对话复核，避免只保留刺激的表述而丢失语境。检查字幕专有名词和说话人变化，再保存交付包。

这次输入说明什么

没有作者字幕时，本地转写可以成为输入步骤，也会增加处理时间。此例与 Jensen 访谈的素材、语言和时长均不同，不能当作严格速度对照，也不能保证其他无字幕视频得到相同数量或质量。首次建议用较短的自有素材跑通流程。
