安装 · Install

一行命令，接进你的 agent。

One line to plug AutoClip into your agent.
# 1. 接入 MCP（需要 ffmpeg） $ claude mcp add-json autoclip '{"command":"uvx","args":["autoclip-mcp"],"env":{"AUTOCLIP_API_KEY":"${AUTOCLIP_API_KEY}"}}' # 2. 装 skill $ npx skills add zhouxiaoka/autoclip # 3. 在对话里说： # 把这个链接做成抖音版 https://youtube.com/…
# ~/.cursor/mcp.json {"mcpServers":{"autoclip":{"command":"uvx","args":["autoclip-mcp"],"env":{"AUTOCLIP_API_KEY":"${env:AUTOCLIP_API_KEY}"}}}}
# ~/.codex/config.toml [mcp_servers.autoclip] command = "uvx" args = ["autoclip-mcp"] env_vars = ["AUTOCLIP_API_KEY"] startup_timeout_sec = 120 tool_timeout_sec = 3600
# 装好 AutoClip CLI 后，一键写入 opencode 配置 $ autoclip mcp install opencode
# 告诉 agent 什么时候调用、怎么交付 $ npx skills add zhouxiaoka/autoclip
# 一条命令出片，--json 给脚本和流水线 $ autoclip produce talk.mp4 --platform youtube_shorts --json

配置里只写 ${AUTOCLIP_API_KEY} 引用，由客户端启动时从环境变量读取，不写明文密钥；也可以不设环境变量，直接在桌面应用的设置里填模型密钥。不要把密钥写进对话。也支持 Ollama / LM Studio 本地模型。

剪辑风格 · Styles

三种风格，说一句就换。

Three editing styles — just ask.
editorial

杂志风

  • 左上角衬线大标题，上方一行小字栏目名
  • 两行字幕放在下方，正在说的词加粗
street

街头风

  • 标题拆成黑底白字粗体条，压在画面顶部
  • 粗体白字幕，重点词垫一条蓝色色块
classic

经典

  • 开头居中一张小标题卡，几秒后自动淡出
  • 单行描边字幕，正在说的词变蓝

同一段素材（黄仁勋做客 Dwarkesh 播客，即案例页里那一期）分别用三种风格实际导出，截取 4 秒，未做后期。

常见问题

你大概想问的。

要花钱吗？

AutoClip 免费、MIT 开源。云端模型按服务商计费；用 Ollama / LM Studio 本地分析没有云端模型费用。

视频在哪处理？

在你本机。产物和桌面应用共用数据目录，CLI / MCP 出的片在桌面首页也能看到。

支持哪些平台？

抖音、小红书、B 站、TikTok、Reels、YouTube Shorts、YouTube 长视频。

任务很长，agent 会超时吗？

MCP 立即返回任务 ID，agent 按 poll_after_sec 轮询。

要装 ffmpeg 吗？

要。没有字幕的视频还需要本地 faster-whisper。
