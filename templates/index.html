AGENT SKILL

刷到喜欢的爆款，变成你的专属模板。

AutoClip 内置 template-cloner 技能包。在 Claude Code 或 Codex 里贴入参考视频，自动拆解字体、布局、节奏动效与 3D 景深层，一键安装到本机。

安装 Agent Skill
npx skills add zhouxiaoka/autoclip
  1. 01在 Claude Code / Codex 里运行上方命令安装 AutoClip 技能包
  2. 02丢给 Agent 一条爆款参考视频，自动生成合规的模板包与预览
  3. 03热装到本机后，桌面端与 CLI 即可直接复用
CLI 一条命令套用模板
autoclip run <video_or_url> --template depth_billboard
